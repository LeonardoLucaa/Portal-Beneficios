Sistema Benefícios

Protótipo de um portal para solicitar bolsa de estudos. Desenhei as telas no Figma e implementei o fluxo principal em HTML, CSS e JavaScript.

O aluno entra, vê a ficha em cards, corrige os itens marcados em vermelho e envia documentos. Os dados são fictícios e não há servidor.

Para rodar, abra o index.html no navegador.

Fora do protótipo: tela inicial com as 8 etapas, anexos com busca, feedback e a visão do setor.
